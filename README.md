# rilke-social-staging

Repo pubblico di staging per la pubblicazione automatica dei contenuti social
del Festival Rilke 2026 (Instagram/Facebook, account "Teatro del Tempo" /
"festival.rilke").

Questo repo resta vuoto tra una pubblicazione e l'altra. Il workflow di
pubblicazione (in rilke-social-automation, repo privato) copia qui il
singolo asset del giorno solo al momento della pubblicazione, per fornire
un URL pubblico richiesto dalla Instagram Graph API. Non contiene quindi
anteprime di contenuti futuri.
